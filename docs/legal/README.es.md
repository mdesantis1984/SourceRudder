## Verificación del release

El gate de release readiness vincula 2.0.0 con los bytes exactos de la `LICENSE`
aprobada y falla si cambian. Es un control técnico de integridad, no asesoramiento
legal.

Las copias históricas de IA_Buscar conservan todos los derechos ya otorgados bajo
MIT. Esas concesiones no pueden retirarse a sus receptores. Cualquier cambio
futuro de licencia debe ser explícito, pasar por el workflow protegido de
contribuciones y aplicarse solo de manera prospectiva.
